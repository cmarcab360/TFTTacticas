# 🏆 **TFTTacticas - Gestiona tus equipos y partidas**

**TFTTacticas** es una plataforma web donde los usuarios pueden crear y gestionar sus equipos, llevar el control de las partidas ganadas/perdidas, y seleccionar sus campeones para cada partida. Los equipos tienen la capacidad de registrar sus estadísticas y seguir el progreso de sus enfrentamientos a lo largo del tiempo.

## 🚀 **Características principales**

- **Creación de equipos:** Los usuarios pueden crear sus propios equipos, definir su nombre y elegir los campeones que los representarán.
- **Control de partidas:** Los equipos pueden registrar los resultados de las partidas (ganadas/perdidas).
- **Estadísticas:** Visualización de estadísticas de las partidas y equipos.
- **Diseño responsivo:** La plataforma está diseñada para ser accesible desde dispositivos móviles y de escritorio.

## 🛠 **Tecnologías utilizadas**

- **Backend:** Laravel (PHP)
- **Frontend:** JavaScript, Blade Templates, SCSS
- **Base de Datos:** MySQL
- **Estilos:** diseño responsivo con SCSS
- **Herramientas:** Git
